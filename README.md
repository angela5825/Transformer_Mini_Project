# **Transformer 기반 모델 조사 - RoBERTa**


### ✅ **RoBERTa** : Robustly Optimized BERT Pretraining Approach 


## **1️⃣ 모델이 발표된 배경** 

RoBERTa는 BERT 이후 다양한 언어 모델이 등장하던 시점에, 새로운 구조를 제안하기보다 BERT가 충분히 잘 학습되었는지를 재검증하기 위해 제안된 모델이다.

2019년 당시에는 연구마다 사용하는 데이터의 규모와 하이퍼파라미터, 연산 환경이 달라 모델 성능을 공정하게 비교하기 어려웠다. 

Facbook AI 연구진은 BERT의 사전 학습과정을 재현하면서 학습 데이터의 양, 학습 시간, 배치 크기 등의 영향을 분석했다.

## **2️⃣ RoBERTa의 구조**

RoBERTa는 Encoder only-구조이다.

이 모델은 기존 BERT의 기본 구조를 유지한 모델로 여러 Transformer Encoder 층으로만 구성되어 있다. 

## **3️⃣ 사전 학습 방식** 

RoBERTa는 BERT와 마찬가지로 **Masked Language Modeling(MLM)** 을 중심으로 사전학습한다. 

### ※ MLM

MLM은 입력 문장 안의 일부 토큰을 가린 뒤, 주변 문맥을 이용해 가려진 원래 토큰을 예측하도록 학습하는 방식이다.

즉 RoBERTa는 문장의 앞뒤 문맥을 함께 참고해서 빈칸의 단어를 맞히도록 학습하는 방식을 이용한다.


## **4️⃣ 기존 Transformer/ BERT와 달라진 점**

### 1) 데이터양 ↑ / 배치 크기 ↑ / 학습 시간 ↑

RoBERTa는 BERT가 충분히 학습되지 않았다고 보고, 더 많은 텍스트 데이터와 큰 배치 크기를 사용하여 도 오래 학습하였다

### 2) NSP (Next Sentence Prediction) 제거

기존 모델의 사전 학습 과제 중 "다음 문장 예측"을 제거했다.
NSP가 성능 향상에 필요하지 않다고 보았기 때문이다.

### ※ NSP란?

예를 들어서 
- 문장 A : 나는 배고프다
- 문장 B: 마라탕을 먹어서 만족했다.
- 문장 C : 학원에 갔다. 

👉 여기서 모델에게 문장 A와 B를 제시하고 문장 B가 문장 A 바로 다음에 이어지는 문장인가 라는 질문을 한다. 

그러면, 모델은
- IsNext : 실제로 다음 문장이다
- NotNext : 전혀 다른 문서에서 가져온 문장이다
중에 하나를 대답할 것이다


따라서, 이 예시 기준으로 
- 문장 A와 문장 B →  모델은 **IsNext**라 답할 것이고
- 문장 B와 문장 C →  **NotNext**라  답할 것이다

👉 BERT는 이런 학습을 통해 문장간의 관계도 학습하려 하였다. 

👉 하지만 RoBERTa는 이 NSP가 실제 성능향상에 꼭 필요하지는 않다고 보고 제거했으며, 대신 더 많은 데이터와 더 긴 문장 묶응을 사용해 MLM 중심으로 학습햇다. 


### 3) 긴 입력 시퀀스 중심 학습  
짧은 문장을 섞어 학습하던 방식 대신, 최대 512토큰 기이의 긴 시퀀스를 학습에 사용했다.

### 4) Dynamic Masking
BERT는 전처리 단계에서 마스킹 위치를 미리 정하는 방식을 적용했지만, RoBERTa는 같은 문장이 학습에 다시 입력될 때마다 마스킹 위치를 새롭게 선택한다.


## **5️⃣ RoBERTa의 강점**

RoBERTa는 
- 문장을 이해하고
- 두 문장의 관계를 판단
- 문서에서 정답을 찾는 자연어 이해 작업
에 강점이 있다

RoBERTa: A Robustly Optimized BERT Pretraining Approach 논문에서 저자들은 GLUE, RACE,SQuAD를 벤치마크로 평가했다

####  ※ GLUE, RACE , SQuAD 

| 이름 | 모델이 하는 일 |
|---|---|
| GLUE | 문장 감성, 문장 유사도, 문장 관계 등을 판단 |
| RACE |  지문·질문·선택지 중 정답 선택- 실제 영어 시험에서 수집한 독해 데이터셋 |
| SQuAD |  답을 문서 안에서 직접 찾아냄 |


## 6️⃣ RoBERTa의 장단점

### 👍 장점

#### 1. 높은 자연어 이해 성능  
   앞에서 말했듯이 RoBERTa는 Encoder-only 모델이다. 
   
   따라서 문장 분류, 감성 분석, 자연어 추론, 문장 유사도 판단, 질의응답처럼 문장의 의미를 이해해야 하는 작업에 강점이 있다.

#### 2. 개선된 사전학습 방식  
   BERT의 구조를 유지하면서도 더 많은 데이터, 더 긴 학습, 큰 배치 크기, NSP 제거, 동적 마스킹 등의 학습 방식을 적용했다.

#### 3. 다양한 분류 작업으로의 Fine-tuning 가능  
   사전학습된 RoBERTa 위에 분류기를 추가하면 감성 분류, 뉴스 분류, 문장 관계 판단 등 여러 작업에 비교적 적은 추가 데이터로 적용할 수 있다. 
   
   본 프로젝트에서는 `klue/roberta-base`를 스킨케어 리뷰의 멀티 라벨 분류 작업에 Fine-tuning하여 활용했다.

#### 4. 문맥을 고려한 표현 학습  
   같은 단어라도 앞뒤 문맥에 따라 다른 의미를 가질 수 있는데, RoBERTa는 문장 전체를 함께 살펴보므로 단어만 따로 보는 방식보다 문맥을 반영한 판단에 유리하다.



### 👎 단점

#### 1. 높은 연산 자원 요구  
   RoBERTa의 성능 향상은 더 많은 데이터, 큰 배치 크기, 긴 학습 시간에 크게 의존한다. 따라서 처음부터 사전학습하려면 많은 GPU와 시간, 데이터가 필요하다. 

#### 2. 모델 크기와 추론 비용  
   RoBERTa는 BERT 계열의 대형 Transformer 모델이므로, 단순한 머신러닝 모델보다 메모리 사용량과 추론 시간이 클 수 있다. 서비스 환경에서는 경량 모델이나 모델 압축을 고려해야 할 수 있다.

#### 3. 생성 작업에는 적합하지 않음  
   RoBERTa는 Encoder-only 구조이므로 문장 분류와 문장 이해에는 적합하다. 하지만,  긴 문장을 순차적으로 생성하는 챗봇·번역·요약 작업에는 Decoder 기반 또는 Encoder-Decoder 기반 모델이 더 적합하다.
